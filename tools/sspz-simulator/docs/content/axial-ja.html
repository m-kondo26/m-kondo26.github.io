このシミュレーションは、取得データの配置と、そこから候補を選んで体軸方向に補間する規則との関係を、展開図とモデルSSPzで確認するためのものです。共通の取得データに対して、候補の選択・補間方法を変えて比較します。

何を計算しているのか

対象は、位置を固定した理想的な点です。検出器の有限開口と、設定した場合には体軸方向の焦点ボケを含む取得応答を求め、ファンビームから平行ビームへの再配列、体軸方向の補間、角度方向の平均、幅Tの矩形平均を行います。得られる曲線を「モデルSSPz（体軸補間応答）」と呼びます。有限径の球を測定する過程は含みません。

現在の公開モデルでは、面内のランプフィルタ、FBPの前処理・逆投影重み、画像ボリュームの再構成は計算していません。3次元のコーン幾何を使うことと、3次元画像再構成を実行することは別です。このモデルをFeldkamp再構成や、特定の装置の2次元・3次元再構成そのものとして解釈しないでください。

角度と展開図の座標

βはX線源の角度、θは再配列後の角度、β₀は基準位相です。本モデルの符号規約ではβ = θ + γとなります。θとθ + 180°は面内で同じ直線方向を共有しますが、体軸方向の位置が異なるため、3次元の光線まで同一直線になるとは限りません。

t = −x sin θ + y cos θ
γ = asin(t / R)
β = θ + γ
L = √(R² − t²) − x cos θ − y sin θ
zᵢ(θ) = h(β − β₀) / (2π) + (i − (N − 1)/2)dL/R
i = 0, …, N − 1

LはX線源から対象点までの面内距離です。列の中心間隔は対象位置ではdL/Rとなります。各列を維持したまま、隣接する取得角度・面内チャネルから線形補間して再配列します。この再配列は両モデルに共通の近似です。

対向方向のX線源角は、この規約ではβ′ = β + 180° − 2γです。ファン角の正方向を逆に定義する資料では「＋2γ」と表されます。式を比較するときには角度の正方向をそろえる必要があります。図の上下を反転するだけで、数式の符号が変わるわけではありません。

展開図では、補間対象の方向を共通の縦軸にして、実データ側を実線・○、対向データ側を破線・△で表示します。△のデータ自身の再配列角は、その補間対象方向から180°離れています。異なる回転、列、焦点状態のデータは、図上で重なっても別のデータとして保持します。縦軸の0°は表示の基準からの角度差であり、物理的なX線源角0°を意味しません。

候補を探す取得角度の範囲

応答を評価する断面位置をzとすると、取得角度範囲の中心はβc = β₀ + 2πz/hです。ファン全角Φに対して、次の有限範囲内のデータから候補を選びます。

βc − (180° + Φ) ≤ β ≤ βc + (180° + Φ)
取得角度範囲の全幅 = 360° + 2Φ

たとえばΦ = 50°では460°です。ここでいうΦはファン全角であり、半角や個々の光線のγではありません。対象位置rを変えてもΦは変わりません。発散なしの比較基準ではΦを0°として扱います。

この範囲は、古典的な対向ビーム補間について、中央の1回転に前後それぞれファン全角分を加える説明を参照したものです。本モデルの多列・簡略応答への適用は明示したモデル上の選択であり、すべての多列CT再構成に共通するデータ充足条件を示すものではありません。

再配列に使用する隣接取得ビューも、この範囲内にあることを確認します。範囲外まで取得角度を丸めて拡張することはありません。この有限範囲の中では、Tや体軸方向の距離による追加の打ち切りを設けません。対象断面を挟む点が得られなければ、支持データ不足として扱います。ピッチを大きくした場合でも、探索を無制限の回転数へ広げることはありません。

取得角度範囲と、展開図の0～360°表示は別です。 図では各補間対象方向の実データ・対向データの関係を1回転に折り返して表示します。数値計算の対向方向ペアを両方向へ展開した表示であり、180°だけで画像を再構成するハーフ再構成を意味しません。

2つの選択・補間規則

候補を統合して2点補間

取得角度範囲内にある実データ側・対向データ側の列中心を合わせ、評価断面zの下側と上側で最も近い点を選びます。選んだ位置をzlo、zhiとすると、線形補間重みは次の通りです。

wlo = (zhi − z) / (zhi − zlo)
whi = (z − zlo) / (zhi − zlo)

同じ位置の候補が複数ある場合は、その位置の重みを等分します。これは現在のモデルの定義です。実データ側を常に優先する規則や、ノイズを最小化する選択を組み込んだものではありません。

RRI相当の列間補間

RRIはrow-to-row interpolation（列間補間）です。取得範囲に入る各方向・各回転について、断面の小数列座標fから各列iの重みmax(0, 1 − |f − i|)を求め、取得できる列の重みで正規化します。2方向とも完全に断面を挟める場合には、2つの通常の線形補間の平均になります。取得範囲によっては、2つより多くの方向・回転の組が含まれます。

検出器端で取得できない列を除いて正規化する処理は、本モデルで明示的に追加した端処理です。数値APIには、重みを持つ各組で完全な挟み込みを求める厳格な設定もあります。1列の場合でも計算できますが、支持のない列重みを外挿して埋めることはありません。

RRI相当の規則はHsiehらの線形補間による比較対象を参照しています。同報の2次式によるCBA（conjugate cone-beam algorithm）は実装していません。候補を統合する規則はHuの隣接サンプル補間の考え方を参照しています。両者の差は、共通の幾何条件における選択・補間規則の差です。幾何だけの効果や、2次元・3次元画像再構成全般の差を直接示すものではありません。

候補の重みからモデルSSPzへ

対象点と取得データを固定し、応答を求める断面位置zを動かします。各位置で候補を選び直し、その重みを取得応答Pkに掛け、角度方向に平均します。その応答を幅Tで矩形平均したものが、正規化前のモデルSSPzです。

A(z) = (2/V) Σ対向方向ペア [Σk wk(z) Pk]
B(z) = (1/T) ∫[z − T/2, z + T/2] A(u) du

1つの中心断面の重みだけを横に広げる計算ではありません。幅T内の各位置uで選び直した候補と重みを積み重ねます。積分は、離散的に求めたA(u)を区分線形とした場合に厳密です。取得ビュー数や体軸方向の計算間隔を無限に細かくした連続系の厳密解という意味ではありません。

焦点幅を指定した場合は、検出器を固定したまま各取得セルの応答を有限焦点にわたって平均してから、再配列・候補選択へ進みます。完成したSSPzを後から平滑化する処理ではありません。候補中心と補間重みは平均焦点位置を使います。焦点幅0では点焦点の計算に戻ります。

既定では各曲線の最小値を0、最大値を1に正規化します。最大値のみでの正規化も選択できます。FWHMとFWTMは、計算格子上の点を線形補間した交点から求めます。設定厚Tへの幅合わせは行いません。計算範囲は応答の裾と幅の交点を確認し、切れた応答から幅を確定しないようにしています。

展開図と動画の読み方

背景の軌跡は列の位置、記号はその条件で選択された点、濃さは補間重みを表します。実データ側・対向データ側・両者の重ね合わせは、同じ計算結果から表示する役割だけを切り替えたものです。別々の図の重みを新たに足して再計算するものではありません。

  • 展開図を描く動画：開始位相を固定し、X線源の取得角度が進むにつれて列の軌跡を描き足します。途中の図からSSPzを計算し直す動画ではありません。
  • 幅T内で断面を動かす動画：断面を−T/2から＋T/2まで動かし、その位置の候補と、そこまで積み重ねた重みを示します。積み重ねの分母は常にTです。最後のフレームで幅全体の重みになります。SSPzパネルは全方向・幅T全体で計算した最終曲線です。
  • 開始角度の変更：固定した対象に対して、X線管の開始角度を1°ずつ変えた360条件を比較します。1回の撮影中の管球回転を示す操作とは異なります。

通常の候補記号は全周から最大約72方向を抜粋します。たとえば2400ビューの場合は60方向です。「30°拡大：間引きなし」では、選んだ30°区間のすべての計算方向を保持し、列の切り替わりを確認できます。区間は下端を含み、上端を含みません。2B・2Cの表示と2Bの画像出力に適用されますが、モデルSSPzや数値出力は常に全計算方向の結果です。

列幅dとピッチpを固定してNを増やすと寝台移動量Ndpが増えますが、局所的な列間隔dL/Rは変わりません。そのため、目的断面付近で選ぶ点数は列数に比例して増えるとは限りません。一方で列の切り替わりが速くなり、通常表示の角度の抜粋では途中の選択を見落とすことがあります。表示されない記号だけを根拠に、そのデータが計算から除外されたとは判断できません。

計算結果の確認と適用範囲

数値出力には丸め前の値と候補の識別情報を保存します。各補間重みを対応する取得応答と角度平均係数に掛けて合計すると、正規化前の応答を再計算できます。対向方向ペアでの表現と全360方向での表現は、同じ応答の別表現です。両方の一覧を加算してはいけません。

任意の体軸方向の焦点切り替え（z-FFS）は既定でOFFです。ONの場合は焦点状態を区別した取得・再配列・候補選択を行い、SSPzにも反映します。有限焦点サイズによるボケとは別の条件です。

独立した候補列挙、取得応答との積和、軌跡との対応、全方向表示、1～320列での支持範囲などを検証しています。これらは宣言したモデルと実装の整合性確認です。臨床装置の再構成性能、コーンビームデータの十分性、画像アーチファクトを検証したものではありません。論文に用いる条件では、ビュー数と体軸方向格子による数値収束を別途確認する必要があります。

過去の有限球・FBP・有限個のシフト加算による結果と、現在のモデルの結果は同一ではありません。過去の数値や原稿図は、使用したモデルと条件を確認して比較してください。
