コーン幾何と列間補間に固定し、回転中心からの評価位置を動かして、展開図のデータ配置・補間重みとモデルSSPzがどう変わるかを確認します。

評価位置を動かして何を見るか

段階モデルでの扱い確認すること

展開図面内はファンパラ変換後の方向で表示し、体軸方向の広がりは保持します。実・対向データの列軌跡、対象位置での列間隔、補間に選ばれる点と重みを読み取ります。

位置プレビューは、入力された開始角度の1条件について展開図とモデルSSPzを連動して更新します。回転中心と周辺を比較するときは、評価半径r以外の撮影条件・開始角度・補間と平均化の設定をそろえます。rはFOV内の評価位置であり、表示FOVの大きさではありません。

展開図の変化が、そのままFWHMの大きな変化になるとは限りません。位置比較で分かるのは、同じコーン幾何のもとでの位置依存性です。再配列や開口・焦点ボケの投影も位置に依存するため、差をコーン角だけの独立した効果とは解釈しません。

何を計算しているのか

対象は、位置を固定した理想的な点です。検出器の有限開口と、設定した場合には体軸方向の焦点ボケを含む取得応答を求め、ファンビームから平行ビームへの再配列、体軸方向の補間、角度方向の平均、幅Tの矩形平均を行います。得られる曲線を「モデルSSPz（体軸補間応答）」と呼びます。有限径の球を測定する過程は含みません。

現在の公開モデルでは、面内のランプフィルタ、FBPの前処理・逆投影重み、画像ボリュームの再構成は計算していません。3次元のコーン幾何を使うことと、3次元画像再構成を実行することは別です。このモデルをFeldkamp再構成や、特定の装置の2次元・3次元再構成そのものとして解釈しないでください。

角度と展開図の座標

βはX線源の角度、θは再配列後の角度、β₀は基準位相です。本モデルの符号規約ではβ = θ + γとなります。θとθ + 180°は面内で同じ直線方向を共有しますが、体軸方向の位置が異なるため、3次元の光線まで同一直線になるとは限りません。

t = −x sin θ + y cos θ
γ = asin(t / R)
β = θ + γ
L = √(R² − t²) − x cos θ − y sin θ
zᵢ(θ) = h(β − β₀) / (2π) + (i − (N − 1)/2)dL/R
i = 0, …, N − 1

LはX線源から対象点までの面内距離です。列の中心間隔は対象位置ではdL/Rとなります。各列を維持したまま、隣接する取得角度・面内チャネルから線形補間して再配列します。回転中心ではL = Rとなり列間隔はdですが、周辺ではLと列間隔が方向によって変わります。ファンパラ変換後も、この体軸方向の広がりは残ります。

対向方向のX線源角は、この規約ではβ′ = β + 180° − 2γです。ファン角の正方向を逆に定義する資料では「＋2γ」と表されます。式を比較するときには角度の正方向をそろえる必要があります。図の上下を反転するだけで、数式の符号が変わるわけではありません。

展開図では、補間対象の方向を共通の縦軸にして、実データ側を実線・○、対向データ側を破線・△で表示します。△のデータ自身の再配列角は、その補間対象方向から180°離れています。異なる回転、列、焦点状態のデータは、図上で重なっても別のデータとして保持します。縦軸の0°は表示の基準からの角度差であり、物理的なX線源角0°を意味しません。

候補を探す取得角度の範囲

応答を評価する断面位置をzとすると、取得角度範囲の中心はβc = β₀ + 2πz/hです。ファン全角Φに対して、次の有限範囲内のデータから候補を選びます。

βc − (180° + Φ) ≤ β ≤ βc + (180° + Φ)
取得角度範囲の全幅 = 360° + 2Φ

たとえばΦ = 50°では460°です。ここでいうΦはファン全角であり、半角や個々の光線のγではありません。対象位置rを変えてもΦは変わりません。

根拠は、Tokiの対向ビーム補間の説明（EP0450152B1、図4～6、図10B）です。中央の360°に前後それぞれファン全角分を加える取得範囲が示されています。この多列・簡略応答への適用は明示したモデル上の選択であり、HsiehらのRRIから一意に決まる範囲でも、すべての多列CT再構成に共通するデータ充足条件でもありません。

再配列に使用する隣接取得ビューも、この範囲内にあることを確認します。範囲外まで取得角度を丸めて拡張することはありません。補間重みは、以下に示す列間隔による範囲を持ちます。Tを探索距離の上限とせず、ピッチを大きくした場合でも探索を無制限の回転数へ広げることはありません。

取得角度範囲と、展開図の0～360°表示は別です。 図では各補間対象方向の実データ・対向データの関係を1回転に折り返して表示します。数値計算の対向方向ペアを両方向へ展開した表示であり、180°だけで画像を再構成するハーフ再構成を意味しません。

列間補間規則

RRI相当の列間補間：候補範囲と根拠

隣接列を使う根拠は、Hsiehら（2007）のRRIの定義です。 原著p.067001-2では、体軸方向に隣接する2列を線形補間すると説明されています。p.067001-4の図5と式(6)、およびp.067001-5冒頭では、実データ側と対向データ側でそれぞれ対象位置を挟む2サンプルを使い、式(6)の関数をξ(Δ, Δ′) = Δとした場合がRRIに対応します。以下の距離による式は、この隣接列の線形補間を本モデルの座標で書き直したものです。独立に「何mmまで」と決めた探索半径ではありません。

RRIはrow-to-row interpolation（列間補間）です。取得範囲に入る各方向・各回転について、断面の小数列座標fから各列iの重みmax(0, 1 − |f − i|)を求め、取得できる列の重みで正規化します。2方向とも完全に断面を挟める場合には、2つの通常の線形補間の平均になります。取得範囲によっては、2つより多くの方向・回転の組が含まれます。

重みが付くのは、目的断面からの距離が、その方向の対象位置での列間隔より小さい列です。 目的断面をz、候補列中心をzᵢ、対象位置に投影した列間隔をsとします。dは回転中心換算の列間隔、Lはその方向の焦点から対象位置までの面内距離、Rは焦点から回転中心までの距離です。正規化前の重みは次の式です。

s = d L/R
qᵢ = max(0, 1 − |zᵢ − z|/s)
wᵢ = qᵢ / Σⱼ qⱼ

分母は取得範囲内の有効な方向・回転・列（焦点移動時は焦点状態も含む）の重みの合計です。たとえばs = 1 mmなら距離1 mm未満の隣接列だけが寄与し、1 mm以上は重み0です。sは位置と方向で変わるため、全条件に固定の「±1 mm」を使うわけではありません。設定スライス厚Tを広げると平均する断面位置の範囲が広がりますが、各断面でのこの局所的な列間補間規則は変えません。

原著に基づく部分と、本モデルで定義した部分は区別します。 完全な実・対向の2組が断面を挟む場合、上記の重みは原著の線形RRIに対応します。一方、検出器端で取得できない列を除き、残った正の重みで再正規化する処理と、取得範囲内に複数回転の組がある場合に全組をまとめて正規化する処理は、本モデルの定義です。原著p.067001-6の図8と本文は検出器端の外挿・対向データによる補償や低ピッチでの複数組を論じていますが、この端処理と合成規則をそのまま指定しているわけではありません。数値APIには有効な各組で完全な挟み込みを要求するstrict方式もあります。1列の入力は可能ですが、列の重みが届かない位置まで外挿はしません。

RRI相当の規則はHsiehらの線形比較法を参照します。同報の2次式のCBAは実装していません。評価位置を変えても、この列間補間規則は共通です。実機の2次元・3次元再構成の優劣を比較するものではありません。

候補の重みからモデルSSPzへ

評価半径rを変える操作は、別の面内位置の応答を計算し直します。以下のz方向の計算は、それぞれのrについて1本のSSPzを作る処理です。rとzは異なる位置を表します。

対象点と取得データを固定し、応答を求める断面位置zを動かします。各位置で候補を選び直し、その重みを取得応答Pkに掛け、角度方向に平均します。その応答を幅Tで矩形平均したものが、正規化前のモデルSSPzです。

A(z) = (2/V) Σ対向方向ペア [Σk wk(z) Pk]
B(z) = (1/T) ∫[z − T/2, z + T/2] A(u) du

1つの中心断面の重みだけを横に広げる計算ではありません。幅T内の各位置uで選び直した候補と重みを積み重ねます。積分は、離散的に求めたA(u)を区分線形とした場合に厳密です。取得ビュー数や体軸方向の計算間隔を無限に細かくした連続系の厳密解という意味ではありません。

焦点幅を指定した場合は、検出器を固定したまま各取得セルの応答を有限焦点にわたって平均してから、再配列・候補選択へ進みます。完成したSSPzを後から平滑化する処理ではありません。候補中心と補間重みは平均焦点位置を使います。焦点幅0では点焦点の計算に戻ります。

既定では各曲線の最小値を0、最大値を1に正規化します。最大値のみでの正規化も選択できます。FWHMとFWTMは、計算格子上の点を線形補間した交点から求めます。設定厚Tへの幅合わせは行いません。計算範囲は応答の裾と幅の交点を確認し、切れた応答から幅を確定しないようにしています。

展開図と動画の読み方

2C(a)「動かした断面の候補点と重み」は、その断面で選ばれた候補点だけを示します。選ばれていない列の背景軌跡は描かず、○を実データ側、△を対向データ側として区別します。2C(b)では、幅T内で積み重ねた重みと列軌跡を対応させて示します。

背景の軌跡は列の位置、記号はその条件で選択された点、濃さは補間重みを表します。実データ側・対向データ側・両者の重ね合わせは、同じ計算結果から表示する役割だけを切り替えたものです。別々の図の重みを新たに足して再計算するものではありません。

  • 展開図を描く動画：開始位相を固定し、X線源の取得角度が進むにつれて列の軌跡を描き足します。途中の図からSSPzを計算し直す動画ではありません。
  • 幅T内で断面を動かす動画：断面を−T/2から＋T/2まで動かし、その位置の候補と、そこまで積み重ねた重みを示します。積み重ねの分母は常にTです。最後のフレームで幅全体の重みになります。SSPzパネルは全方向・幅T全体で計算した最終曲線です。
  • 開始角度の変更：固定した対象に対して、X線管の開始角度を1°ずつ変えた360条件を比較します。1回の撮影中の管球回転を示す操作とは異なります。

通常の候補記号は全周から最大約72方向を抜粋します。たとえば2400ビューの場合は60方向です。「30°拡大：間引きなし」では、選んだ30°区間のすべての計算方向を保持し、列の切り替わりを確認できます。区間は下端を含み、上端を含みません。2B・2Cの表示と2Bの画像出力に適用されますが、モデルSSPzや数値出力は常に全計算方向の結果です。

列幅dとピッチpを固定してNを増やすと寝台移動量Ndpが増えますが、局所的な列間隔dL/Rは変わりません。そのため、目的断面付近で選ぶ点数は列数に比例して増えるとは限りません。一方で列の切り替わりが速くなり、通常表示の角度の抜粋では途中の選択を見落とすことがあります。表示されない記号だけを根拠に、そのデータが計算から除外されたとは判断できません。

計算結果の確認と適用範囲

SSPzの両端は、最小値を差し引く正規化の前に確認します。端に応答が残る場合は、z方向の標本間隔を保って計算範囲を広げ、全開始角度を共通の格子で再計算します。計算上限の±80 mmでも確認できない条件では幅を確定しません。実際の計算範囲は数値出力に保存します。

数値出力には丸め前の値と候補の識別情報を保存します。各補間重みを対応する取得応答と角度平均係数に掛けて合計すると、正規化前の応答を再計算できます。対向方向ペアでの表現と全360方向での表現は、同じ応答の別表現です。両方の一覧を加算してはいけません。

任意の体軸方向の焦点切り替え（z-FFS）は既定でOFFです。ONの場合は焦点状態を区別した取得・再配列・候補選択を行い、SSPzにも反映します。有限焦点サイズによるボケとは別の条件です。

独立した候補列挙、取得応答との積和、軌跡との対応、全方向表示、1～320列での支持範囲などを検証しています。これらは宣言したモデルと実装の整合性確認です。臨床装置の再構成性能、コーンビームデータの十分性、画像アーチファクトを検証したものではありません。論文に用いる条件では、ビュー数と体軸方向格子による数値収束を別途確認する必要があります。

過去の有限球・FBP・有限個のシフト加算による結果と、現在のモデルの結果は同一ではありません。過去の数値や原稿図は、使用したモデルと条件を確認して比較してください。

旧モデルの数値APIについて

数値APIには過去の検証用として最寄り2点モデルと発散なしの基準を残していますが、通常画面の選択肢には含めません。発散なしの基準は、回転中心相当の一定列間隔を使い、ファンパラ変換を省略する別の取得仮定です。2026-09-24.1より前は最寄り2点・取得範囲360°でしたが、同版以降のmatched-rri条件では列間補間と360°＋2Φを用います。旧結果は現在のコーン幾何の結果として再利用せず、計算版と条件を区別します。

この旧基準の座標はγ = 0、β = θ、L = R、列間隔はs = dとし、zᵢ = h(θ − β₀)/(2π) + (i − (N − 1)/2)dです。過去のコーン幾何との比較を再検証する場合は、両者ともz-FFSをOFFにします。

同じ評価点のモデルTSP

SSPzは体軸位置ごとの応答、TSPは固定した評価点への取得時刻ごとの寄与を示します。ここでのTSPは、同じ点対象の強さを時刻ごとに変えたときの、目的断面z₀における線形モデルの応答です。SSPzを寝台速度で時間へ換算する方法は使いません。

元の実取得ビューをv、列・チャネルをr,c、点対象の取得信号をqᵥᵣ꜀、再配列・列間補間・幅Tの平均・角度平均を含む係数をAᵥᵣ꜀とすると、Kᵥ = Σᵣ,꜀ Aᵥᵣ꜀qᵥᵣ꜀です。取得時刻ごとの点の強さgᵥに対し、応答はy(z₀;g) = Σᵥ Kᵥgᵥとなります。ΣᵥKᵥは、正規化前のSSPzのz=0における応答と一致します。単なる補間重みの総和ではなく、取得信号を掛けた寄与です。

Vを1回転の実取得ビュー数、Trotを回転時間とし、時刻はtᵥ = (v/V)Trotとします。時刻0は基準ビューで、負のビューや複数回転を保持します。再配列後の角度を取得時刻とはせず、元の角度・チャネル補間係数を通して実取得ビューへ戻します。同じデータの実側・対向側での使用は同じ取得時刻へ合算します。z-FFSも元の交互取得順序を保持します。

表示はKᵥ/max Kᵥです。内部の寄与0のビューを含む等間隔格子を使い、正の寄与範囲の両端に0の点を一つずつ加えます。等価幅はTeq = (Trot/V)ΣᵥKᵥ/max Kᵥ、寄与90%区間は累積寄与が初めて5%と95%に到達するビューの時刻差です。後者は離散ビューによる値で、FWHMとは異なります。中心応答が0の場合はTSPを定義しません。

回転時間の入力は0.05～5秒／回転、初期値0.5秒です。回転時間だけを変えた場合、一定ピッチの本モデルでは同じデータ幾何を保ち、時間軸と時間幅だけを比例換算します。JSON・CSVには元のビュー、相対時刻、ミリ秒、未正規化寄与を記録します。

元投影の特定ビューだけに信号を与える時間インパルス、交互ビュー、時間窓での応答を再計算し、ΣᵥKᵥgᵥと照合しています。これは実装の確認です。時間インパルスによるTSP評価の考え方はIchikawaら（2015）を参照していますが、本モデルは面内フィルタ・逆投影・画像ROI測定を含まず、同論文の実機画像TSPとの同等性を示すものではありません。
