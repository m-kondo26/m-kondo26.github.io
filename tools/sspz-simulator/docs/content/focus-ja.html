焦点ボケは、X線源が体軸方向に有限の大きさを持つことで、検出器の取得応答に広がりが生じる効果です。このモデルでは、各検出器セルの取得値を焦点内で平均してから、再配列、候補の選択、体軸補間、角度方向の平均、幅Tの矩形平均化を行います。完成したSSPzに、後からボケを加える処理ではありません。

焦点サイズと焦点移動は別の設定です

焦点サイズfは、一つの取得時点における焦点の広がりです。体軸方向の焦点移動（z-FFS）は、取得ごとに焦点の中心位置をA・B間で切り替える設定です。両方を有効にした場合は、それぞれのA・B位置を中心とする有限焦点からの信号を、その取得の中で平均します。焦点サイズを増やしても、取得ビュー数や独立した露光の数は増えません。

入力値と出典

量このモデルでの意味
f体軸方向の実効焦点サイズ。焦点内の強度分布は一様とします。単位はmmです。
R焦点から回転中心までの距離（mm）。
D焦点から検出器までの公称距離（mm）。検出器は公称管球位置に対して固定します。
d・a回転中心換算の検出器列幅dと、面内方向の有効開口幅a。面内チャネル間隔とは区別します。

新規・リセット時のf＝1.2mm、D＝1070mmは、森ら『CTとMRI』（コロナ社）の図6.6（印刷ページ60）の例に基づきます。同図のR＝600mmと回転中心―検出器距離470mmから、D＝1070mmとしています。1.2mmは実効焦点寸法なので、ターゲット角7°の正弦をもう一度掛けません。これらは書籍の説明例であり、特定装置の仕様ではありません。

焦点サイズf＝0は点焦点の計算です。過去の点焦点条件を保存したURLと数値APIの既定値は、この条件を維持します。有限焦点では、すべての取得角度で評価点の先に検出器があるように、D > R＋rを要求します。z-FFSと併用する場合の拡大率はM＝D/Rとし、相反する距離と拡大率は受け付けません。

検出器を固定したまま、焦点内の位置を変えます

評価点を面内座標(r, 0)、体軸座標zoに置きます。取得角度をβ、公称の管球・検出器の体軸位置をb、z-FFSによる焦点中心の移動をδ（OFFでは0）とします。焦点内の位置tは、−f/2から＋f/2までです。

L = √[(R cosβ − r)² + (R sinβ)²]
source_z(t) = b + δ + t
w_ray(t) = R(z_o − b − δ − t) / L
w_det(t) = w_ray(t) + R(δ + t) / D

Lは焦点と評価点の面内距離です。wrayは移動した焦点を基準にした光線の座標、wdetは固定された検出器上の座標です。どの検出器列に光線が入るかはwdetで判定し、光線の幾何に応じた係数にはwrayを使います。この二つを同じにすると、焦点と一緒に検出器まで動かした計算になってしまいます。

評価点に投影した検出器開口の幅Azと、焦点によるボケの広がりBzは、次のとおりです。

A_z = d L/R
B_z = f |1 − L/D|

R＝600mm、D＝1070mm、f＝1.2mmでは、回転中心のBzは約0.527mmです。一つの列の応答が存在する範囲はAz＋Bzになります。ただし、裾が広がることとFWHMが大きくなることは同義ではありません。最終的なモデルSSPzには、さらに候補選択と平均化が含まれます。

各取得セルの値からSSPzまで

  1. 焦点内の各位置について、理想的な点対象を通る光線と、固定検出器との交点を求めます。
  2. その光線が入る検出器セルの値を、焦点全体で一様に平均します。焦点の総重みは1です。
  3. 平均後の取得値に、共通の再配列・体軸補間・平均化を適用し、モデルSSPzを求めます。

一つの焦点位置の点対象応答J(t)と、列kの平均取得値は、以下の式で計算します。区間[tlo, thi]は、その列の開口に入る焦点位置と[−f/2, ＋f/2]との共通部分です。

J(t) = √[R² + w_ray(t)²] / [L² (a/R) d]
P_k = (1/f) ∫[t_lo, t_hi] J(t) dt

積分は解析的な原始関数で計算し、短い区間でも桁落ちを抑える形で評価します。検出器端の外に外れた寄与は取得されないため、その分を再正規化して埋め合わせません。面内チャネルの境界では、従来の半分ずつの所属規則を維持します。

候補列の中心軌跡と補間係数は、焦点の中心位置で定義したままです。有限焦点によって変わるのは、選択されたセルが取得する信号です。これは公称光線に基づく近似です。SSPzの計算範囲は、追加された焦点ボケの裾を含むように広げますが、取得角度範囲、ビュー数、設定幅Tは変えません。

評価位置による変化と適用範囲

現在の画面はコーン幾何に固定しています。評価半径rを変えると、各方向のLが変わり、開口の投影幅Azと焦点ボケの支持幅Bzにも反映されます。位置を比べるときは焦点寸法fと距離R・Dをそろえ、展開図とモデルSSPzを対応させて確認します。

面内方向の焦点ボケ、ヒール効果、ターゲット傾斜による見かけの焦点形状の変化、ノイズは扱いません。書籍の図6.25や市販装置の画像再構成を厳密に再現するモデルでもありません。関連する書籍の説明は、印刷ページ58〜60の式(6.6)〜(6.10)・図6.6、およびページ72〜74の式(6.34)・図6.25です。

実装は、焦点を細かく分割して固定検出器へ直接投影する独立計算と照合しています。応答の存在範囲、総重み、z-FFSとの併用、候補係数の不変性、取得値から応答までの一致、f＝0での過去の出力との一致を確認しています。これらは定義したモデルの計算整合性の確認であり、装置固有の焦点形状や実測SSPzとの一致を示すものではありません。

旧モデルAPIの補足：過去の検証用に残した発散なしの基準では、回転中心換算のB0＝f(1−R/D)を位置・角度によらず一定とします。通常画面の選択肢ではなく、有限焦点の平行ビーム装置を再現する定義でもありません。
