この計算は、寝台を静止させたときに、再構成する体軸位置によってSSPzがどう変わるかを示します。検出器列の配置、列間の線形補間、距離に応じた重み、1回転分の合算を順に確認できます。

寝台静止時の再構成位置とSSPzを開く

曲線が表すもの

各曲線は、検出器の各列が回転中心軸に投影される位置に、再構成面を一つずつ固定して求めた応答です。例えば16列なら16個の再構成位置を評価します。一つの曲線を求める途中では、投影角度に応じて隣接する列を選び直します。そのため、各曲線は一つの検出器列だけの寄与を表すものではありません。

森一生ほか『CTとMRI―その原理と装置技術―』のpp.72–74、式6.34、図6.24–6.25を参照しています。本書はFeldkamp法の逆投影を踏まえて説明していますが、この計算で取り出しているのは体軸方向の応答です。面内のランプフィルタや画像全体への逆投影を含む、Feldkamp画像再構成の全過程は計算していません。

本体から引き継ぐ設定

本体のリンクから開いた場合は、現在の検出器列数N（1～320）、1列幅d、線源―回転中心距離R、線源―検出器距離D、体軸方向の実効焦点寸法、評価半径、1回転のview数、z刻みを引き継ぎます。1列幅dは列ピッチと開口幅の両方に使います。引き継いだN個の再構成位置について計算し、指定した評価半径と回転中心を比較します。

寝台移動は0に固定します。本体で選択したヘリカル補間方式、幅Tの矩形平均化、面内の有限開口と再配列、焦点の交互移動（z-FFS）は適用しません。このため、本体の2次元用・3次元用という選択に依存しない、独立した参照計算として表示します。本体の計算については体軸方向の補間応答モデルを参照してください。

幾何から列中心とぼけ幅を求める

距離の単位はmmです。βを線源の回転角、rを評価半径とし、線源のz位置を0に固定します。列番号kは式の中では0からN−1です。aは回転中心換算の検出器開口幅で、この計算ではa＝dとします。

線源位置             Sβ = (R cosβ, R sinβ, 0)
横断面内評価位置     (r, 0)
線源からの横断面内距離 Lβ = √(R² + r² − 2Rr cosβ)
局所倍率             αβ = Lβ / R
回転中心換算の列中心 qk = [k − (N−1)/2]d
評価位置での列中心   cβk = αβ qk
評価位置での開口幅   aβ = αβ a
焦点によるぼけ幅     bβ = f |1 − Lβ/D|

fは体軸方向の実効焦点幅です。検出器を固定したまま線源を体軸方向にtだけ動かすと、横断面内距離Lβにある位置ではレイがt(1−Lβ/D)だけ動きます。この関係からbβを求めます。参照条件の回転中心では、開口幅は2 mm、焦点ぼけ幅は1.2 × (1−600/1070)＝約0.5271 mmです。

有限焦点は、体軸方向に固定した実効線分上の一様分布として近似します。面内の焦点ぼけ、傾斜ターゲット上の二次元焦点、視方向による見掛け焦点の変化、ヒール効果は含みません。また、各焦点位置で候補列を選び直す計算ではありません。詳しくは有限焦点の取り扱いを参照してください。

再構成面を挟む列を選ぶ

再構成面jはZ＝qjに固定します。各角度で、投影された列中心がcβk ≤ Z ≤ cβ,k+1を満たす隣接2列を選び、次の線形重みを与えます。

wβk   = (cβ,k+1 − Z) / (cβ,k+1 − cβk)
wβ,k+1 = (Z − cβk) / (cβ,k+1 − cβk)

列中心と再構成面が一致すれば、その列の重みを1にします。再構成面が最端列の外側にある場合は、最も近い端列を重み1で代用します。この代用は、書籍にある内側データの利用を踏まえた、明示的なモデル上の選択です。書籍には代替演算の完全な仕様は示されていません。

端列代用では再構成面を両側から挟めていません。その角度の数と割合を別に記録し、通常の列間補間と区別します。この割合だけで、画像再構成に必要なデータが足りているかを判断することはできません。

各角度の応答を合算する

横軸zは、固定した再構成面に対して信号を置く体軸位置です。Πは区間内で1、区間外で0の矩形関数、＊は畳み込みを表します。

検出器応答       BD,βk(z) = Π[(z − cβk)/aβ]
焦点応答         BF,β(z) = (1/bβ) Π[z/bβ]       （bβ > 0）
基礎応答         Bβk(z) = BF,β ＊ BD,βk
列間補間後       hβj(z) = Σk wβk Bβk(z)
距離の重み       Wβ = (R/Lβ)²
1回転の合算      Hj(z) = (1/M) Σβ Wβ hβj(z)
最終SSPz         SSPj(z) = Hj(z) / ∫Hj(z) dz

検出器応答BDは高さ1、面積aβです。焦点応答BFは、焦点の投影幅が変わっても総線源強度を保つという仮定により、面積1とします。畳み込み後のBは面積aβを保つ台形になり、両幅が等しいと三角形になります。焦点幅を0に設定した場合は、検出器の矩形応答に戻ります。検出器開口の説明も参照してください。

各角度のBを面積1にしてから平均する処理は行いません。角度別の面積寄与はWβaβとなります。本書p.72には基礎応答の場所依存を回転中心の値で代表する近似も述べられていますが、本計算では開口幅と焦点ぼけ幅の局所的な幾何倍率を使います。

距離重みR²/Lβ²は、本書pp.20–21の等角ファン座標での距離因子に対応します。円弧検出器の幾何を用いているため、平面検出器の距離式を再配列なしに代入しません。この因子を使うことだけで、FDK全体を実装したことにはなりません。

最終SSPzは各曲線の面積が1になるように正規化します。動画の途中では、全角度を合算した最終面積を分母に使います。途中の曲線を毎回面積1に戻さず、応答が積み重なる過程を示します。

数値表示と検証の範囲

台形の基礎応答を各zビン内で解析的に積分し、ビン平均として描きます。計算範囲には全列・全角度の開口と焦点半影を含め、支持域を切る外部指定グリッドは受け付けません。列数を増やした際に、view数やz刻みを自動的に粗くする処理はありません。

重心とσは、連続的な基礎応答の解析モーメントから求めます。各基礎応答の分散は(aβ²＋bβ²)/12です。このσは一つのSSPz自体の広がりであり、開始角度間のFWHMの標準偏差ではありません。FWHMは表示ビン間を線形補間した外側の半値交点間の距離です。多峰性の曲線では途中の谷も含むため、FWHMだけで形状全体を要約しません。

実装の検証では、独立した列交差計算と解析モーメント、回転中心の既知の応答、左右対称性、360°周期性、角度別の寄与和、累積表示の終端、面積正規化、表示刻みの収束を確認します。1・4・80・160・320列の検証では、支持域、列の間隔、端列代用、正規化も対象としています。

これらは定義した演算の実装検証です。図6.25の数値データや実機測定との外部検証ではなく、同図の完全な再現や、実機の再構成性能を保証するものではありません。
