The transaxial detector aperture is the width over which one channel receives signal. Channel spacing is the distance between adjacent channel centres. The simulator uses both as shared acquisition settings when comparing candidate selection and axial interpolation.

Three detector dimensions

SettingMeaningModel definition
Row width dDetector-row width along the axial directionBoth the axial aperture and row-centre spacing equal d.
Transaxial aperture aActive width of a transaxial channelThe projection signal is integrated over this width to obtain the cell average.
Channel spacing cDistance between adjacent channel centresThe acquisition spacing must satisfy 0 < a ≤ c.

All three values are in millimetres projected to isocentre. They are different from physical detector dimensions and output-image pixel spacing. An aperture narrower than the channel spacing leaves an inactive gap. Signal in that gap is not redistributed to neighbouring channels.

Why the default is 0.58 mm

New and reset settings use 0.58 mm for both transaxial aperture and channel spacing. This is an approximate isocentre value based on the geometry in CT and MRI: a physical detector spacing of approximately 1.03 mm, a source–axis distance of 600 mm and a source–detector distance of 1070 mm.

1.03 × 600 / 1070 ≈ 0.58 mm

The default assumes an aperture equal to the spacing, with no inactive gaps. It is not a measured aperture specification for a particular scanner. Opening a URL with saved settings uses the values stored in that URL.

Where aperture enters the SSPz calculation

  1. For a fixed point object, calculate the signal acquired by each view, channel and row, including the finite detector aperture and configured focal size.
  2. Rebin the acquired data row by row, select candidates using the chosen method, and apply linear axial interpolation.
  3. Average over angle and apply an axial rectangular average of width T, the configured slice thickness. Normalize the result for the displayed model SSPz.

Aperture affects the acquired signal before interpolation. The object is an ideal unit-integral point, not a finite sphere. The two cone-geometry interpolation methods share the acquired signal. The parallel-beam approximation uses the same cell dimensions with a separate, explicitly nondivergent reference geometry.

See axial interpolation and model SSPz for candidate selection and averaging, and focal-blur calculation for the finite source.

How this differs from a finer calculation grid

A smaller SSPz calculation step samples the calculated response more finely. It does not reduce the detector aperture or acquisition spacing. Changing channel spacing at fixed aperture also changes acquisition sampling.

Aperture is not a universal lower bound on FWHM. Geometry, interpolation, averaging and normalization also matter. The model does not fit or clip FWHM to the aperture width or configured slice thickness.

Acquired signal for a point focus

At a focal size of 0 mm, the cone-geometry detector-cell signal is defined by the following equation. With a finite focus, the signal is integrated over the source extent.

Pjk = √(R² + w²) / [L² (a/R) d] × Aj(γ) × Bk(w)

SymbolMeaning
R, LSource–axis distance and transverse source–point distance
γ, wPoint-object fan angle and axial coordinate on the detector cylinder of radius R
a, dTransaxial aperture and row width projected to isocentre
j, kTransaxial channel and axial detector row
A, BMembership factors: 1 inside the aperture, 1/2 exactly on its boundary, and 0 outside

For axial object position zo and source position zs, w = R(zo − zs)/L. The parallel-reference cell signal is AjBk/(ad). An even transaxial channel grid places its centres symmetrically on either side of the axis.

Scope of the model

The response includes acquisition geometry, finite aperture, focal size, candidate selection, axial interpolation and averaging. It omits the transaxial ramp filter and transverse image backprojection, so it does not directly reproduce a scanner’s image-based SSPz. Changes introduced with finite aperture also involve channel sampling, readout and geometric projection amplitude.

Detector-cell integrals, boundaries, gaps and equality of acquired samples between the methods have been checked against analytic values, numerical integration and implementation comparisons. These checks establish computational consistency; they do not validate a particular clinical scanner.
