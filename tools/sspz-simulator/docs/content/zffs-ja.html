体軸方向の焦点移動（z-FFS: axial flying focal spot）は、取得ごとに焦点の位置をA・B間で切り替える設定です。通常はOFFです。ONにすると、取得応答、候補点の幾何、再配列、補間重み、モデルSSPzをまとめて変更します。表示だけに点を足す機能ではありません。

このページで説明するのは、固定した円筒型検出器に対して焦点が体軸方向だけに移動する理想化モデルです。装置固有の焦点移動や画像再構成を再現したものではありません。

総ビュー数は、ONにしても増えません

Vは1回転あたりの実際の取得回数の合計です。A・Bを交互に取得するため、Vは偶数とし、各焦点位置での取得はV/2回になります。同じ角度にもう一つの露光を追加する計算ではありません。各焦点位置のビュー数をOFF時とそろえる比較では、総ビュー数Vを明示的に2倍に設定する必要があります。

新規・リセット時はz-FFSがOFF、共通の実効焦点サイズが1.2mm、公称焦点―検出器距離Dが1070mmです。有限焦点は各露光内で積分します。焦点サイズ0では従来の点焦点計算を維持し、過去のURLに記録された条件も保持します。焦点サイズによるボケと、ここでの焦点中心の移動は別の効果です。

取得位置の定義

Nを検出器列数、dを回転中心換算の列間隔、pをビームピッチ、h＝Ndpを1回転の寝台移動量、φを開始角度とします。取得番号vは、前後の回転を表す負の番号も含めて保持します。M＝D/Rは拡大率、qは焦点片側の回転中心換算の移動量を列間隔で表した値です。既定値はq＝0.25です。

β_v = φ + 2πv/V
b_v = hv/V
δ = qd / (1 − 1/M)
δ_v = −δ（vが偶数：焦点A）
δ_v = +δ（vが奇数：焦点B）

評価点を(r, 0)とすると、面内の光線長Lvと、検出器列kの中心を評価点へ投影した体軸位置zvkは次のとおりです。列番号kは0からN−1です。

L_v = √[(R cosβ_v − r)² + (R sinβ_v)²]
z_vk = b_v + δ_v(1 − L_v/D)
       + [k − (N−1)/2] d L_v/R

回転中心では、仮に同じ公称角度・寝台位置にA・Bを置いた場合、既定値で両者の位置差はd/2になります。実際のA・B取得では角度と寝台位置も異なります。周辺ではLvに応じて列間隔と焦点移動による位置差が変わるため、一様な倍密度になるとは仮定していません。

参考としたMori, “Antialiasing backprojection for helical MDCT” (2008)の図4・式(19)〜(22)は、交互の焦点位置と不等間隔のサンプリングを扱います。従来の例ではR＝600mm、D＝1072mmでしたが、現在の新規条件は『CTとMRI』図6.6に基づく共通のD＝1070mmからMを求めます。過去のz-FFS条件の距離は保持します。論文のシフト逆投影、画像フィルタ処理、アーチファクト抑制の結果は、このモデルに実装したものではありません。

点対象の取得応答

OFF時と同じ、総量1の理想的な点対象と有限の検出器開口を使います。球の直径は導入しません。点対象の体軸位置をzo、面内の有効開口幅をaとすると、点焦点での式は以下になります。

γ = atan2(−r sinβ_v, R − r cosβ_v)
w_ray = R(z_o − b_v − δ_v) / L_v
w_det = w_ray + δ_v/M
P = √(R² + w_ray²) / [L_v² (a/R) d]

光線がそのセルに入る場合にPを与えます。検出器列への所属はwdet、光線の係数はwrayで判定・評価し、検出器を焦点と一緒に移動させません。有限焦点では、この判定と応答を焦点内で積分してから再配列します。面内チャネル間隔と有効開口幅は共通の別入力であり、検出器の隙間には応答を割り当てません。

再配列からSSPzまで

  1. A・Bのデータを分け、それぞれ同じ焦点で取得した前後のビュー（取得番号差2）と隣接チャネルから共通の平行方向へ再配列します。
  2. Aの実データ側・Bの実データ側・Aの対向データ側・Bの対向データ側という四つの列群から、選択した補間規則に従って候補と重みを求めます。
  3. 点対象を固定して評価断面を動かし、共通の幅Tの矩形平均化、正規化、数値サンプル上での幅測定を行います。

A・Bを区別せず隣接ビュー同士で補間すると、焦点の切り替えを一つの連続した列軌跡として扱ってしまいます。そのため、焦点ごとの再配列が必要です。幾何は目的光線の連続的な取得角度で評価しますが、有限ビュー数での線形再配列は近似です。

候補を統合するモデルでは、四つの列群の和集合から断面を挟む最近傍の候補を選び、完全に同じ位置の候補には重みを分配します。RRI相当のモデルでは、各列群の線形補間重みを求め、取得できる列群の間で正規化します。この四群への拡張は、本シミュレーションで定義したもので、Moriの再構成法そのものではありません。焦点移動量が正確に0の場合には、重なる焦点軌跡を通常の全ビューの再配列格子に戻し、OFF時の応答を浮動小数点精度で再現します。

候補の取得範囲は共通の有限なX線源角度範囲で、360°＋2Φです。Φはファン全角です。再配列に重みがあるすべての元ビューが、この範囲に入ることを要求します。同じ方向群でも複数回転分が条件を満たす場合には、それらを同じ補間規則で扱います。詳細は体軸補間とモデルSSPzの計算を参照してください。

展開図と書き出しを読むとき

焦点A、焦点B、A＋B、選択された取得データの重みを、同じ軸で表示します。ここでの角度は取得角度であり、再配列後の角度ではありません。原点βrefは断面を中心とした取得角度範囲の始点です。角度表示は0〜360°に折り返しますが、元の取得番号と回転番号は保持します。角度の表示範囲は10°・60°・360°から選べます。

取得データの重みは、焦点ごとの角度・チャネル補間と幅Tの平均化を逆にたどって求めます。図の各列の重みはチャネルの係数を合算し、角度方向の平均係数を含みます。濃さの最大値は図の下に示します。これは重みであり、対象信号への寄与やSSPzの高さとは異なります。

CSV・Excel・JSONには、個々のセルの係数、焦点、列、チャネル、元の取得番号、実際の焦点位置、取得値を保存します。セルの係数に角度平均係数と取得値を掛け、全取得データで合計すると、正規化前の中心応答が得られます。拡大表示の外にあるデータも、その合計には含みます。JSONには中間の再配列後の重みも保存します。PNGは画面と同じ描画処理を使い、数値書き出しでは丸め前の値を保持します。

確認したことと、確認していないこと

独立した直交座標での光線計算、中心での焦点間隔、負の取得番号のA・B判定、同じ焦点内の再配列、四群の重み、応答の直接計算、OFFおよび移動量0との一致、4・80・160・320列での条件比較、取得セルの重みから応答までの一致を確認しています。これらは定義したモデル内での実装の整合性を確認するものです。

装置の露光時間、陽極に関係した半径方向の焦点移動、ノイズ、対象の動き、製造者固有のタイミングは扱いません。完全な3次元FBPや画像再構成、アーチファクト抑制の立証、論文用の計算条件の収束性確認とも異なります。総Vを固定すると各焦点の角度サンプル数は半分になるため、その影響を焦点移動そのものの効果と混同しないことが必要です。
