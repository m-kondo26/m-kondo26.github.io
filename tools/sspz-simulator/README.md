# CT展開図・SSPz幾何リファレンス

0～360°フルスキャンの実取得データ幾何と、明示的に選択した体軸方向重みの仮定を用いて、次の関係をブラウザ上で可視化する研究・教育用静的Webアプリです。

1. 横断面内位置と、1回転寝台移動量内の全360モデル状態
2. 0°以上360°未満の実取得X線データ、および検出器列・回転の候補
3. 目的断面の体軸座標 `z0` より小さい側・大きい側にある最近接候補間隔と設定厚の比 `Δz/T`
4. 最近接2候補の線形補間重み
5. 設定厚反映後の説明用SSPzの中心形状と低振幅裾
6. 半値幅（FWHM）、10%幅（FWTM）、標準偏差

表示順は、(1) 設定厚反映後のモデルSSPzの中心形状、(2) 同じモデルSSPzの低振幅裾、(3) 幅指標です。候補重み由来の中間SSPzは公開図・幅評価・CSVへ出力せず、候補離散性 `Δz/T` のヒートマップだけを計算経路の補助表示として残しています。SSPzは1回転寝台移動量を360等分した相対再構成状態について、360本を間引かず独立した細線として描き、中央値や最小値―最大値の帯を重ねません。各曲線は状態ごとにピークを1へ正規化し、各状態の再構成面を0とする `z - z0` 座標から追加の位置合わせを行いません。したがって、位置移動と形状変形の両方を保持します。

1回転内の幅変動図は、設定スライス厚を反映したモデルSSPzだけを表示します。設定厚適用前の中間SSPz幅は再構成スライス厚と誤解されるため、幅変動の選択肢から除外しています。幅指標の選択は共有URLへ保存されます。旧URLに `stage=base` が残っていても、その指定は移行時に破棄し、設定厚反映後の幅を表示します。

この360状態は、360回の撮影、360投影、または実測した絶対X線管角度ではありません。1回転寝台移動量内の相対再構成位置を360等分したものです。一方、入力欄の「1回転の相対X線管角度サンプル数」は、各1本のSSPzを0～360°フルスキャンで積算するビュー数です。両者は別の標本化です。

3Dの選択状態SSPzは、設定厚反映後応答の10%水準以上を含むよう、`z - z0 = 0`を中心とする対称横軸へ自動調整します。全360状態の重ね書きでは、中心形状を10%以上の線形軸、低振幅裾を0.1%以上の対数軸へ分離します。コーン幾何を反映しない／反映する2条件は、中心形状どうし、裾どうしでそれぞれ共通横軸を用います。

入力するのは設定スライス厚 `T` であり、FWHMの目標値ではありません。各相対X線管角度で、理想ヘリカル軌道上から目的断面の体軸座標 `z0` より小さい側・大きい側にある最近接候補を探索し、両者の間を線形補間します。これは展開図の上下方向を意味しません。固定した候補支持幅や回転数で探索を打ち切りません。この中間SSPzへ、設定厚と同幅の等重み矩形窓を順方向に作用させた結果を主要な説明用SSPzとして示します。FWHM、FWTM、標準偏差はいずれも設定厚反映後のSSPzから求める主出力であり、商用装置の非公開再構成を再現しません。

## 目的

本ツールの主眼はSSPzの数値だけを求めることではありません。展開図から得られる候補重みへ設定スライス厚を反映し、その360状態を中心形状と低振幅裾に分けて重ね合わせることで、取得幾何が設定厚に対して位置、幅、裾および非対称性の変化へつながる可能性を直感的に追跡できるようにします。`Δz/T` はこの計算経路を補足する幾何参照です。ここで `Δz` は目的断面の体軸座標 `z0` より小さい側と大きい側にある最近接候補間隔、`T` は設定スライス厚です。「小さい側・大きい側」は `z` 座標の大小を意味し、展開図の上下方向を意味しません。

展開図は二段構成です。上段は `z0` より小さい側・大きい側の最近接候補を含む回転とその前後1回転を自動導出し、その範囲内の0～360°実取得データと全検出器列の候補軌跡を俯瞰します。下段は各角度で実際に選択された両候補を拡大します。上段の淡い帯は下段の横軸範囲と一致します。

検出器列は色で区別し、0～360°の実取得データはすべて実線と円で示します。180～360°を対向データへ置換する処理はありません。重み点の大きさは一定とし、同じ列色の中で淡色から濃色になるほど、各相対X線管角度内で正規化した線形補間重みが大きいことを示します。

コーン幾何あり条件の距離倍率は `q(β)=L(β)/R=sqrt(1+(r/R)^2-2(r/R)cosβ)` です。`R` はX線焦点―回転中心距離、`r` は回転中心―評価点距離、`β` は評価点と同じ方向にX線焦点がある位置を0°とする相対X線管角度、`L(β)` はX線焦点―評価点距離です。`q` は0°から180°まで増加し、180°から360°まで減少します。一方、平行ビーム近似との差 `q-1` は1回転内で符号が変わるため、その影響の絶対値は途中で小さくなってから再び大きくなります。候補列中心は、ヘリカル寝台移動による直線項と、`q(β)` で周期的に伸縮する検出器列オフセットの和です。したがって、コーン幾何ありの展開図では候補線が1回転内で徐々に曲がり、360°で元の距離倍率へ戻ります。

理想的なヘリカル軌道は無限に続くため、固定した20回転などで「撮影全体の全幾何」を表すことはできません。計算は `z0` より小さい側・大きい側の候補が見つかるまで回転範囲を拡張します。俯瞰図だけは有限表示とする必要があるため、全検出器列の行ごとの最近接両候補を含む回転と、その前後1回転を描きます。列数が25以上でも代表列へ間引かず、320列まで全列を描画します。

1回転内の相対位置も取得条件として入力させません。全360状態を常に自動計算し、結果側のスライダーは、そのうちどの1状態の展開図とSSPzを詳しく見るかを選ぶ閲覧操作です。これは実測した絶対X線管角度ではありません。

## 実行

日本語版は `index.html`、英語版は `index-en.html` をダブルクリックするだけで起動できます。Google Chromeの `file://` 直接起動でも計算できる構成です。両ページ右上の言語切替は、現在の計算条件をURLクエリとして引き継ぎます。

ローカルファイル実行を組織のブラウザ設定が禁止している場合は、`起動_サーバー.cmd`をダブルクリックしてください。Pythonによるローカルサーバーを起動し、既定ブラウザを開きます。表示された黒い画面でEnterキーを押すとサーバーを終了します。

手動で起動する場合は、次の静的サーバー方式を使用します。

単純な静的ファイルなので、Pythonがあれば次のコマンドで起動できます。

```powershell
python -m http.server 4173
```

ブラウザで `http://localhost:4173/` を開きます。計算はWeb Worker内で行われ、サーバーへ入力値を送信しません。

## 検証

```powershell
npm run build
npm test
```

`npm run build` は、ローカルファイルからも動作する一体化JavaScriptを生成します。`npm test` は、0～360°の実取得データだけが使われること、180°前後で計算規則が変わらないこと、`z0` より小さい側・大きい側の最近接候補の線形重みが各ビュー内で1へ正規化されること、0°と360°でヘリカル軌道が1回転分だけ平行移動して連続すること、角度サンプル数に対する数値収束を検査します。さらに、設定厚を変えても内部中間SSPzが変わらないこと、80列・半径250 mmの全360状態で人工的な欠測が生じないこと、焦点―評価点距離が0～180°で増加し180～360°で減少すること、4・80・320列で全列を保持することも検査します。公開出力の取り違えを防ぐため、160列×0.5 mm、ビームピッチ1.35、設定厚1.0 mmの条件で、公開FWHMが約1.037 mm、内部中間FWHMが約0.643 mmであることも固定回帰条件としています。

公開画面の横断面内位置プリセットは、特定研究の測定位置へ偏らないよう、回転中心からの距離0、50、100、150、200、250 mmとしています。250 mmは直径500 mmのFOV（撮影・再構成視野）の幾何学的辺縁であり、装置固有の有効範囲を保証する値ではありません。回帰試験に残る102 mmは独立したフルスキャン参照計算との数値一致を確認する固定条件であり、推奨プリセットではありません。

## 投稿図出力

Web画面は日本語版と英語版を同じ計算核および作図処理から生成します。両版で次の作図規約を共通化します。

- 軸・文字は黒、補助グリッドは淡い灰色とし、色は条件または検出器列の識別に限定する。
- 変数名に続けて単位を丸括弧で示し、同一軸の目盛はすべて同じ小数桁数にする。
- 目盛間隔は1、2、5と10の整数べきの系列から選び、軸端はその目盛間隔の整数倍へ外側に丸める。たとえば必要範囲が±132 mmなら±150 mmなどへ丸める。ただし、全候補が±300 mmを超える条件を±150 mmへ切り詰めることはせず、±400 mmなど全データを含む次の切りのよい端点を用いる。
- 主目盛は軸の外側、副目盛は内側に置き、原則として各軸を5区間以上に分割する。
- 比較するパネルは役割ごとに同一の軸範囲を用いる。360状態SSPzでは、中心形状の左右2パネル、低振幅裾の左右2パネルでそれぞれ共通横軸を用い、中心形状と裾の軸範囲は混在させない。Δz/Tマップは左右で同一の線形カラースケールを用いる。
- 図内の長い説明や多数の数値は避け、凡例の符号化を直交させる。展開図では色＝検出器列、実線・円＝0～360°の実取得データ、濃淡＝線形補間重みとする。

各図の「投稿用PNG（600 dpi）」は、画面を単純拡大せず、投稿寸法で再描画します。単一パネルは80 mm幅（1890 px）、全幅図は180 mm幅（4252 px）とし、PNG内にも約600 dpiの物理解像度情報を記録します。画面上の選択状態マーカー、候補数などの長い操作説明、重複する題名・副題は投稿用出力から除外し、軸、データ、必要最小限の凡例を優先します。詳細条件はfigure captionに記載してください。

この規約は、Medical Physicsの[Author Guidelines](https://aapm.onlinelibrary.wiley.com/hub/journal/24734209/about/author-guidelines)およびWileyの[Electronic Artwork Guidelines](https://authorservices.wiley.com/asset/photos/electronic_artwork_guidelines.pdf)を参照しています。投稿原稿内の表は画像化せず、編集可能な表として作成し、単位を列見出しへ置き、略語は脚注で定義してください。英語版の用語は、下記のWangら、Schallerら、Kudoらの研究で使用された表現を参照し、本Web独自の説明語と先行研究のアルゴリズム名を区別します。軸範囲、目盛、線幅、色、投稿寸法の規則は両言語版で変更しません。

## GitHub Pagesで公開

1. このフォルダを新しいGitHubリポジトリのルートとして登録します。
2. 既定ブランチを `main` としてpushします。
3. GitHubの `Settings` → `Pages` → `Build and deployment` で `GitHub Actions` を選択します。
4. `.github/workflows/deploy-pages.yml` が回帰試験に合格した後、静的サイトを公開します。

公開用リポジトリの作成、公開・非公開の選択、著者名、ライセンスは研究責任者が確認してから設定してください。本フォルダには意図的にライセンスファイルを含めていません。

## モデルの範囲

実装しているもの：

- 0～360°フルスキャンの実取得データ幾何（各ビューを等角度重みで積算）
- 中心化した検出器列座標と複数回転候補
- 目的断面の体軸座標 `z0` より小さい側・大きい側にある最近接2候補の自動探索
- 最近接2候補間の線形補間重み
- 設定厚に対する候補離散性 `Δz/T`
- 単位面積の矩形検出器列応答
- 設定スライス厚と同幅の等重み矩形窓による後段の説明モデル
- X線焦点―評価点距離の角度変化を、候補列位置と列幅へ反映する理想化補正の有無

実装していないもの：

- Schallerの適応的体軸補間そのもの
- Feldkamp法などの三次元逆投影
- TCOT・MUSCOT固有の投影選択・重み付け
- 装置固有の冗長度重み、コーンビーム重み、逆投影重み
- 反復再構成、深層学習再構成、ノイズ
- 時間感度プロファイル（TSP）および動体応答

このため、出力は装置固有の定量予測ではなく、設定厚に対する候補幾何の離散性、SSPz変動可能性、および設定厚の写像仮定による形状差を理解するための参照です。矩形窓モデルを「実機の5 mm直接再構成」と読み替えないでください。特に矩形窓が内部の候補重み応答より十分広い場合、最終FWHMは窓幅にほぼ拘束されます。この平坦性は幾何学的影響の消失を意味しないため、Δz/T、設定厚反映後SSPzの中心形状と低振幅裾、FWTM/T、および標準偏差/Tを併記します。患者診療や商用装置の性能保証には使用しないでください。

## 計算モデルの文献的背景

Web画面には、モデル開発時に参照した以下の研究と、本Web版での実装境界を表示しています。

- Wang and Vannier (1994), spatial variation of SSP in spiral CT, https://doi.org/10.1118/1.597199
- Wang et al. (2003), SSP in multi-row-detector spiral CT, https://doi.org/10.3233/XST-2003-00064
- Schaller et al. (2000), multislice spiral interpolation theory, https://doi.org/10.1109/42.887832
- Kudo et al. (2004), exact and approximate helical cone-beam CT algorithms, https://doi.org/10.1088/0031-9155/49/13/011

これらは研究系譜と計算上の判断を追跡するための文献です。現在のWeb版は、Wangらの180°ハーフスキャン、Schallerらの適応的体軸補間、Kudoらの正確・近似コーンビーム再構成をそのまま実装していません。

## 主要ファイル

- `index.html`: 日本語版の画面構造
- `index-en.html`: ビルドで生成する英語版の画面構造
- `styles.css`: PC・モバイル表示
- `app.js`: 入力、描画、CSV/PNG出力、URL共有
- `worker.js`: 非同期計算と進捗・中止
- `sim-core.js`: ブラウザ・Node共通の計算核
- `app-bundle.js`、`worker-source.js`: 日本語版のダブルクリック起動用生成ファイル
- `app-bundle-en.js`、`worker-source-en.js`: 英語版のダブルクリック起動用生成ファイル
- `scripts/build-standalone.mjs`: 日英両版の生成処理
- `scripts/english-replacements.mjs`: 先行研究の用語に合わせた英語表示辞書
- `tests/`: フルスキャン計算契約と固定数値の回帰試験
- `model-manifest.json`: モデル版、基準コード・固定データのハッシュ、実装範囲
- `REPRODUCIBILITY.md`: 数値回帰・ブラウザQA・公開手順の記録
- `.github/workflows/deploy-pages.yml`: GitHub Pages公開処理
